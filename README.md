# SpendTracker releases

Downloads and the update feed for SpendTracker, a Windows app by [Lilly Labs](https://lillylabs.co.za) for tracking and categorising bank transactions. Your data stays in a local SQLite file on your machine.

**Download:** grab `SpendTracker-win-Setup.exe` from the [latest release](https://github.com/lilly-labs/spend-tracker-releases/releases/latest).

Installed copies check this repo for updates. The source code is private; this repo holds release builds only.
